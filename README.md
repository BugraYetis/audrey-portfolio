## 📌 Proje Hakkında

Webflow üzerinde geliştirdiğim yaratıcı ajans portfolyo sitesi. GSAP SplitText ile karakter animasyonları, Draggable ile sürüklenebilir ekip carousel'i ve mouse-trail parçacık sistemi içeriyor.
